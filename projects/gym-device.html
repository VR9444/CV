Gym Performance Evaluation Device Naprava za oceno vadbene zmogljivosti

Embedded Fitness Device | 2025 Vgrajena fitnes naprava | 2025

Overview Pregled

Compact embedded device for measuring force and motion on gym cable machines. Uses strain-gauge load cell and 6-axis IMU to classify movement phases in real time. Kompaktna vgrajena naprava za merjenje sile in gibanja na fitnes napravah s kabli. Uporablja merilno celico s tenzometrom in 6-osni IMU senzor za razvrščanje faz gibanja v realnem času.

Streams data over BLE to a React Native + TypeScript mobile app for live visualization, automatic phase detection, and training analysis. Pošilja podatke prek BLE v mobilno aplikacijo React Native + TypeScript za vizualizacijo v živo, samodejno prepoznavo faz in analizo vadbe.

Key Features Ključne funkcije

  • Wireless real-time BLE data streamingBrezžični BLE prenos podatkov v realnem času
  • On-device phase classification using IMU and load cellRazpoznavanje faz gibanja na napravi z uporabo IMU in merilne celice
  • High-resolution 24-bit ADC force sensingMerjenje sile z visoko ločljivostjo prek 24-bitnega ADC
  • Mobile dashboard for live analytics and exercise reviewMobilna nadzorna plošča za analizo in pregled vadbe
  • Configurable profiles and local data loggingNastavljivi profili in lokalno shranjevanje podatkov

Technology Stack Tehnološki sklad

  • Microcontroller:Mikrokrmilnik: ESP32-WROOM-32E (FreeRTOS, C++)
  • Sensors:Senzorji: 24-bitni ADC, 6-osni IMU
  • Mobile App:Mobilna aplikacija: React Native, TypeScript, SQLite
  • 3D Design:3D načrtovanje: Onshape
  • Manufacturing:Izdelava: Elegoo Saturn 4 Ultra (resin) & Creality Ender 3 (FDM)

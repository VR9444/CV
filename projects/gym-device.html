Gym Performance Evaluation Device

Embedded Fitness Device | 2025

Overview

This project introduces a compact embedded device designed to measure and analyze user performance on gym cable machines. It combines force sensing and motion tracking to evaluate workout phases in real time, offering precise insights into exercise form and efficiency.

The system connects wirelessly to a React Native + TypeScript mobile app, where live data visualization, workout logging, and automatic phase recognition help users and trainers monitor strength performance more effectively.

Key Features

  • Wireless real-time data transmission to mobile app
  • Embedded algorithm for detecting movement phases
  • High-resolution force and motion tracking
  • Mobile dashboard for exercise visualization and analytics
  • Configurable profiles and local data logging

Technology Stack

  • Microcontroller: ESP32-WROOM-32E
  • Sensors: Load cell amplifier, 6-axis IMU
  • Firmware: C++ (ESP-IDF + FreeRTOS)
  • Mobile App: React Native, TypeScript, WatermelonDB
  • Data Storage: LittleFS (on-device), Local SQLite (mobile)
  • 3D Design: Onshape + Elegoo Saturn 4 Ultra resin printing
